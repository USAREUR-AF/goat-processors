      Pipeline

        Proposals waiting

        A person or an agent proposed a different pack. Nothing changes until someone allowed to change the runner approves it.

          Pick packs

          A pack is the set of rules one function runs with. Pick the pack for one function; the runner uses it from the next report on, and records the change so a replay of the record gives the same result.

          Pause or resume

          Replay a file

          Run a recorded file through a separate copy of the pipeline. The live runner and its output do not change. A file can be a scenario vector, JSON lines of reports, or a record the runner wrote.

          Explain a track

          Why the runner made one system track: the events and the checks (trace records) behind it, from the recent steps the runner keeps.

          For the full step-by-step viewer (plan, slider, every record), run the command above with -o json on the runner, or replay a record with tools/explain.
