# Fieldkit scope guard allow list (runner/fieldkit/check-scope.py).
#
# Every action a Fieldkit tool declares must be a row here: the tool, the
# goat-processors CLI verb it equals, and the API route it calls. A tool can do
# only what the CLI can do (goatcore docs/design/fieldkit-and-bleating-edge.md
# §1, §5 "No new authority"). Adding a row adds an action to a tool, so it is
# reviewed with the CLI verb it names.
#
# tool      | goat-processors verb | method | route
processors  | view                 | GET    | /v1/view
processors  | pack use             | PUT    | /v1/pipeline/{function}
processors  | stop                 | POST   | /v1/stop
processors  | start                | POST   | /v1/start
processors  | replay               | POST   | /v1/replay
processors  | explain              | GET    | /v1/explain/{track}
processors  | proposal approve     | POST   | /v1/proposals/{id}/approve
processors  | proposal reject      | POST   | /v1/proposals/{id}/reject
