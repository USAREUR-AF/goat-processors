What it is

The functions that work on track data after it is translated. goat-transformers translates messages into one shared report model; goat-processors reads that model.

A function is a specification

correlate, fuse, filter and quality are each one document in spec/. Each runs as load_pack, then ingest(report) and tick(now_ms), and snapshot() returns its whole state.

A pack is a settings file

packs/<function>-<name>/pack.def names which specified tests run and with which limits. A pack holds no code and no expressions.

Seven engines must agree

Python, Rust, Go, Java, C++, Erlang and Zig, each standard library only, each written from the specification and the vectors alone. Every pull request runs every vector in all seven.

Every decision is in the trace

Each test is one record: what it compared, the value it computed, the limit and the result. This is step 3 of 04-separation-dissolves.json, copied from the vector:

{"stage": "gate", "a": "radar-1/T1", "b": "adsb/A7",
 "test": "mahalanobis", "value": 0.10957452680004903,
 "limit": 9.21, "pass": true}

The value is the squared distance between the two tracks in units of their combined uncertainty. The limit is the pack line gate mahalanobis gate=9.21. Open any vector in the replay viewer, a single HTML page that works offline:

python3 -I tools/explain/explain.py \
  packs/correlate-gnn/vectors/04-separation-dissolves.json

Seven engines check each other

The specification and the hand-stated decisions are the reference. Every vector is computed by the Rust engine and accepted only when all seven engines agree: each generator, tools/make-*-vectors.py, states its scenarios' decisions by hand, refuses a vector whose events differ from them, and writes a vector only when every engine reproduces its events, trace and final snapshot. Every engine is written from the specification and the vectors alone, never from another engine's source. Numbers must match within a relative 1e-6.

Scored against ground truth

The correlate packs run on generated scenarios: crossing, formation, splitting and turning objects; sensors with bias, latency, low detection, track number swaps and false tracks; sensors whose clocks are offset or drifting. F1 runs from 0 to 1 and scores whether the output puts two tracks together exactly when they are one object. GOSPA is a mean position error that also charges missed and false tracks.

The default pack, assign-time, on the 500 random scenarios of the evaluation set, which no pack is tuned on: F1 0.934 (0.921 to 0.947), equal within the 95 % interval to window and assign-full; GOSPA 268 m.

Working with AI agents

The processors stay fast and exact, with no model inside the engines. AI agents connect at the edges, through the same doors a person uses, and every agent action is logged with the identity it acts for. Each tile says Built only when its code and tests are on main.

Built

Connect an AI assistant

An MCP server in the runner (Model Context Protocol, the common way an assistant calls a program's tools). An assistant reads tracks and quality marks and proposes changes, with no more authority than its user.

Built

Agents as sources

An agent publishes tracks under its own name, marked as agent-derived with its model, and the processors take them in like any sensor. Hints that settle a hard case ("keep A and B apart") are Designed.

Built

Proposals someone approves

An agent proposes another pack; a person approves it, or a site rule does, within the packs it allows and after its gate passes. Every call and change is logged and can be reverted.

Built

Ask "why?"

A plain-language answer to "why were these two tracks joined?", in which every sentence cites the trace record it comes from.

Each site chooses the model its agent features may use, local or hosted, and the highest level of data sent to it. The guide to building your own integration has one runnable example per built interface, each run in CI: Built.

Quick start

Each engine and tool uses only its language's standard library.

git clone https://github.com/USAREUR-AF/goat-processors
cd goat-processors

# run every vector in one language
cd engines/python && PYTHONPATH=src python3 -m unittest discover -s tests && cd ../..

# replay every vector, with an index page
python3 -I tools/explain/explain.py --all build/explain
